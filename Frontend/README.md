# DimentionGear Frontend

Frontend React pentru aplicatia e-commerce DimentionGear.

## Stack

- React
- TypeScript
- Vite
- SCSS modules
- React Router
- Three.js / React Three Fiber

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Structura

- `src/app` - componenta radacina si configurarea rutelor
- `src/pages` - pagini principale: home, produse, configurator, cos, checkout
- `src/features` - module de business: catalog, configurator, cart
- `src/shared` - layout-uri, stiluri globale si cod reutilizabil
- `public/models` - modele 3D statice `.glb` / `.gltf`
